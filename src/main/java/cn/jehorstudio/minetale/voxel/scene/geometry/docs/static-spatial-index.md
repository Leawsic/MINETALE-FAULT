# 静态空间索引与按需 High

## 来源与离线边界

Raw 是几何来源，Low 是按资产 `low_step` 预生成的体素表示；清单显式保存米制采样间距。`SceneIndexCompiler` 与运行时共同编译 `SceneSurface`、`SceneSubdivision` 和边界算法，生成 `.mtscene 1.0` 的可选静态索引。Core 保存拟合控制点和局部支撑数据，通用模型保存求值后的三角形索引；High 曲面和 1/8 米体素在请求时生成。

32 米页是 IO 和可见性单位，8 米砖是 High 接管单位。砖目录覆盖 Low 几何和拟合后 Raw 控制面的保守影响范围并集。来源面关联包含一格 High Halo；查询闭区间接触砖边界时也纳入来源。Raw-only 砖和必要的附加空 Low 页拥有独立目录项。

`SceneLowVolume` 保存 Low 实际小数格点的原点和采样间距。输入 Low 使用采样格点上的闭合轴对齐矩形表面。离线工具归并跨页矩形片段，再沿 X 轴扫描线恢复实体占用。Low 的局部外形须在导出前与 Raw 对齐。

每砖的六向截面由确认的 Low 占用生成，复用共面 Low 和原有材质映射。截面按连续 64 个砖分组并使用 XZ 压缩；运行时按需解码并缓存当前组，砖目录保存独立字节数和 SHA-256。High 表面数量为零时也读取并上传截面。带静态索引的资产生成 High 时直接读取索引数据，索引数据提供来源关系、截面和材质映射。

## 可见性与增量调度

`SceneIndex` 持有紧凑页 AABB 树和砖目录。相机位置、model-view、投影、模式或剔除设置变化时，`SceneRuntime` 重建可见页、页内可见砖和近场需求；完全相同的视点复用集合。上传完成或回收只标记所属页及六邻接砖所属页的绘制缓存；每帧拼接这些缓存并保留主视锥裁剪。

相机到砖 AABB 的进入/退出距离为 96/120 米。候选按距离排序，全部需求参与生成和上传。遮挡和离开视野的任务会取消；已完成成果保留到失效或卸载。

砖完成几何、材质、mip 和上传 fence 后接管。空 High 也属于完成状态。截面由已接管砖持有：两侧 Low 或两侧 High 隐藏共享截面，一侧 High、一侧 Low 时显示指向 High 区域的截面。就绪状态和需求状态共同决定当前接管，GPU 缓冲状态独立于该判断。

## 保守页级遮挡

`SceneVisibility` 在页范围内使用世界对齐的 2 米单元。遮挡标记来源限定为同时被 Low 完整包含并被 Raw 可靠闭合实体包含的单元。Raw 判定先扩展一格 High Halo，使单元与相关曲面影响包围盒分离，再执行闭合部件内外判定；遮挡证明采用闭合部件结果。

离线 flood fill 保存每页六个边界的连通位掩码。空页参与传播，High 任务数量为零。运行时状态为“页、进入方向”；相机位于范围外时从朝向相机的外边界页进入，位于范围内时保守连接相机页的所有开口。相机位于可靠遮挡单元时回退空间树查询。视锥外页停止传播；可到达的遮挡边界页继续绘制。

该图表达可靠实体造成的区域隔离，适用于从外部观察 Core，包括孔洞、凹陷、部件间隙和近表面；逐像素遮挡负责精确判定。Core 当前 7,480 个图节点均为六向互通，运行时直接跳过传播；已测外部视点的页级遮挡收益为零。人工封闭墙体的验证场景可以排除墙后页，开孔后恢复通行。`culling false` 同时关闭视锥和页级遮挡；Raw 白板调试只使用视锥。

## 工作线程与内存

`SceneSurface` 及其 CC 缓存、生成工作区只由单一工作线程修改。局部 CC 使用预生成的支撑面、局部顶点列表和折痕子集。砖直接读取来源面关联；内部射线继续查询部件 BVH，批量求值缺失曲面片，保持砖内表面数量为零时的外部空间判断。局部曲面按来源面共享，三角形数组与曲面查询树均计入缓存统计。

`SceneVoxels` 拥有并按尺寸保留工作区，复用 64³ 加一格 Halo 的原生数组、代数标记和方向切片列表。Greedy 使用单个切片掩码。每份完成的 `Page` 独立拥有顶点、采样和纹素数组；Page 交付后保持待上传结果稳定。新曲面片 BVH 使用中位选择划分。

`stats` 区分 `preparedMiB`（待交接数组）、`workspaceMiB`（工作区容量快照）、`curveCacheMiB`（缓存曲面和 BVH）、`indexPayloadMiB`（索引原生数据估计）以及 GPU 数据。索引估计覆盖原生数据；Java 对象头、HashMap、Slot、原始控制拓扑和 ZipFile 由离线报告单独统计。拟合曲面交接后，待解码字节统计结束，曲面缓存承接对应占用。离线报告另用 Instrumentation 统计索引与曲面的可达 Java 堆，并记录生成过程的采样堆峰值。GPU 统计和 Java 堆统计分开记录。

## 输入约束与工具

缺少静态索引的资产在装载时求解控制笼，并按定时规划选择需求。声明静态索引的资产必须通过格式、来源和数据指纹验证；验证失败时明确报告并使用 Low。损坏截面的砖保留 Low。资源重载重新读取快照；generation 令牌取消旧任务。

字段顺序、端序和容量边界见[.mtscene 文件契约](../../asset/docs/mtscene-format.md)。Raw 重新导出会移除静态索引，重新预处理后再发布。
