# 固定几何与纹理生命周期

| 来源 | 几何处理 | 所有者 |
|---|---|---|
| `raw` 普通主体 | MSVT 以 0.5 米体素离线合并；3,656 个四边面 | `SceneFixed` |
| `立方体.072`、`立方体.075`、`立方体.076` | 保留原始网格的位置和逐角法线 | `SceneFixed` |
| `needs_subdivision` 的 11 个部件 | 控制多边形与硬折痕；生成 Low 和局部 High | `SceneSurface`、`SceneRuntime` |

固定几何全量常驻、全量提交，材质固定为每米 2 个样本。15 个图集批次完成一次烘焙后常驻，光影出口四通道和两级 mip 共约 325 MiB。相机移动时直接复用已完成图集。精度命令、Greedy 和距离调度只改变细分组。

发布包保存固定几何、原始材质来源三角形和面采样参数。加载线程建立来源 BVH，并逐批重建材质样本和图集索引；这些展开数组只服务当前批次，上传完成后释放。材质来源严格等距时使用三角形目录顺序，保持确定性。

加载时先显示完整白板，材质按批次就绪后替换对应白板。卸载等待在途来源读取结束后关闭资产，GPU 资源在末次绘制的 fence 后释放。原生和 Iris 输出复用同一材质采样流程。

导出器先启用来源集合并更新依赖图，再把每个对象的位置、旋转和缩放转换为场景坐标。固定几何与细分控制网格遵循相同的世界变换规则。

Core 的 11 个细分部件几何上限为 2，9 个管状部件的材质上限为 2，两座塔的材质上限为 8。空间索引的来源关联决定每砖上限，多来源砖分别取最大值。默认管道在全通道 0.5 与全通道 2 之间切换，固定主体始终使用 2。

材质法线采用纹素中心及两个切线正方向邻点的单格差分，保留阶跃和单格交替细节；颜色保持四点采样，缩小过滤由 mip 处理，见[程序化材质](procedural-materials.md)。
