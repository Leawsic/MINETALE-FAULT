# 部件实例、LOD 与表面附着

`SceneParts` 读取共享原型、四档几何、图集和摆放记录。`SceneInstances` 拥有原型 GPU 缓冲、图集及可见实例矩阵；`SceneAttachments` 拥有摆放种子与当前接触位置。阵列副本复用同一网格，通过原型副本矩阵与摆放矩阵组合。

## 运行时

每个原型包含 2–4 档 LOD；编号越大越精细，低优先级原型缺省最高精度档。选择依据为目录中的几何误差估计、实例变换的最大拉伸上界、视距和窗口像素高度。最大拉伸取 G=MᵀM 最大绝对行和的平方根（Gershgorin 上界）：正交（旋转/镜像＋缩放）时等于精确的最大奇异值，含剪切时仅带交叉项绝对值的微小保守余量。投影误差超过 5 像素时升级，低于 3 像素时降级。误差来自源体素间距及来源变换，是保守估计，不是网格之间实测的 Hausdorff 距离。原型的 `priority` 字段是准入需求乘数（缺省 1，低优先级原型小于 1），只影响精细网格的准入排序，不影响 LOD 选择阈值。

全部原型常驻 LOD1–LOD2（静态层，见下），初始化只建立元数据并预留固定偏移，解码任务与动态几何、图集统一经调度入口逐步派发，兜底层不依赖可见性，部件不会因精细网格回收而消失。可见实例按需请求精细级别，请求按屏幕误差优先级排序，连续等待时优先级随时间增长以限定低优先级网格的饿死上界。几何、图集与静态解码共用最多两个在途任务槽；待上传几何（含解码缓存恢复的网格）达到 64 MiB 后暂停新增冷读取（图集与缓存命中不受此几何门槛约束），空队列仍放行单个大网格。动态请求先取得预算与连续区间预留，才恢复缓存或提交读取；预留成功但尚未完整上传的网格不可绘制、不可驱逐，失败或脱离需求时预留只归还一次。上传长期速率上限 64 MiB/s、突发 4 MiB，长期上限与帧率解耦；计时起点在实际传输阶段，准入规划不挤占额度，单帧纹理像素转换与顶点编码共用 2 ms CPU 软预算，超时让出、令牌保留。新网格及其全部图集完成上传后才用于绘制，期间选择已就绪的较粗级别。图集请求与可见性解耦，任何被引用的图集最终就绪。精细网格准入受动态预算线约束，预算不足时按 LRU 回收超过 2 秒未使用且未被请求的网格筹资，筹不到的稳定降级到粗级兜底；每帧至多驱逐 8 个网格，区间经 fence 归还合并。回收网格的解码结果保留在至多 128 MiB 的 CPU 缓存，重新驻留时直接复用；脱离需求的已解码数据归还该缓存。

全部驻留网格共用单一顶点 arena。LOD1–LOD2 全量常驻于前缀固定偏移、永不驱逐；容量在初始化时一次定为静态层加 min(准入余量, 精细层全量)，其中准入余量为预算余额扣除图集规划总量（按图集尺寸与通道构成精确计算）再加一个增长步进——被保护的当前需求可短暂超出软预算。运行期不增长、不搬移数据；分配按整段 best-fit，碎片只推迟准入。无连续空闲段时把空闲段与可驱逐冷网格按地址组成有序区间，滑动窗口挑选能容纳目标且驱逐字节最少的连续窗口并整体预约：预约窗口（含 fence 归还后的部分）对普通分配独占，空闲部分扣住防切碎，待驱逐对象由每帧驱逐额度分帧释放成形；fence 完成后目标优先取得窗口，没有可行窗口时保留请求元数据等待条件变化。一轮准入只建立一次驱逐候选集合，各请求顺序消费。统计分别报告图集、网格驻留、arena 容量、待退休、待上传与解码缓存的字节数。

绘制按原型、LOD 和镜像绕序分组；同一图集的组共享一个渲染通道，网格共用 arena 顶点缓冲与两半式共享索引（前半 CCW、后半 CW，索引值各自从 0 计，第二半以元素偏移寻址），镜像经元素偏移寻址，每组的实例基址在矩阵打包时固定、由每次 draw 的 setup 更新。实测部分驱动上 baseInstance/多重间接子绘制存在性能悬崖，MDI 提交路径经评估后移除。`drawIndexed` 的实例数为组内副本数。SSBO 中每个副本包含 112 bytes：位置变换三行、逆转置法线变换三行及 handedness。镜像副本使用相反绕序，切线经实例变换后重新正交化。矩阵缓冲每次提交更新存储，避免覆盖 GPU 尚未读取的数据。统计报告 advance/draw 的 CPU 耗时指数均值。

## 附着

维护表的归一化 `anchor` 在目标包围盒中恢复搜索种子。`attachment_normal` 保存 raw 来源接触面的单位法线；加载线程沿该轴与真实 Low 三角形和固定 Mesh 求交，取搜索半径内最近的交点。缺省法线的旧资源使用最近点。搜索限制由目标范围及 `search_radius` 共同确定。Low 的候选目录同时覆盖搜索范围内的空砖，使新 High 表面可以参与附着。

`raw.blend` 决定资产是否存在及作者摆放关系，转换后的体素几何决定实际接触范围。局部方向没有有效交点时，保留种子与偏移对应的作者位置；统计 `authoredFallback` 记录此类实例数量。离线落地调整依据转换后底面分布：跨台阶部件选主要支撑平台，大型复合底座使用小量偏移；原工程已有的跨空结构保持作者布局。

High 生成线程计算候选接触点；渲染线程仅在对应几何上传完成并发布接管时采用该候选。降回 Low 时恢复其候选。固定 Mesh 始终参与比较。位置在叠加维护表偏移后吸附到 0.125 米格点，旋转与缩放保持作者设置；轴转换保留 Blender 原坐标中的 half-up 平局方向。

目标范围提供空间约束，不是逐三角形对象归属标记。包围盒重叠的来源对象应通过种子和搜索半径消除歧义。部件当前均为不透明材质。

## 材质与 Iris

编译器联合去重 color、normal、specular 图块，输出 lossless WebP；图集按首次使用的 LOD 分组。常量图块精确折叠，区域保留边距和一层 mip。普通材质使用 2× 采样、颜色调色板、方向法线量化及粗糙度/金属度标量量化。降低最高几何档后的材质按原最高档密度烘焙，再沿用原最高档的 2× 降采样及颜色、法线和标量量化；替换后裁除无引用的图块和图集。

normal 使用 LabPBR 的切线法线与 AO 约定；specular 保存 smoothness、反射率/金属编码和 emission。源 Principled 的连续 metalness 无法直接等同于 LabPBR：高金属区使用 albedo F0，其余区域使用混合 F0 的标量亮度近似。离线素材中的颜色协调计算在打包时应用。

无光影时读取颜色和 emission，使用几何法线进行方向明暗计算。Iris 启用时加载 normal/specular 并沿用 `SceneTexture` 的 PBR 绑定。实例与 Core 主体统一在主视图 terrain 阶段提交；实例 Shader 入口应用实例变换。场景仅提交主视图绘制，不参与阴影投射。

卸载、资源重载和世界切换由场景生命周期统一回收；异步读取结束后关闭资产，GPU 缓冲和图集在 fence 完成后释放。每次实例绘制结束后恢复借用的 SSBO 绑定并关闭实例变换开关。
