# terrain 纹理区域契约

## 数据契约

Iris 的 `mc_midTexCoord` 表示面覆盖的纹理区域中心。[Iris 属性契约](https://shaders.properties/current/reference/attributes/mc_midtexcoord/)

区域角点必须提供一致的范围和原点。三角形 UV 重心、普通斜向 UV 的包围盒中心和裁剪后保留的父面中心属于契约外的区域定义。材质路径使用重建 UV、颜色路径使用原 UV 时，会出现三角形材质错位；坐标重建独立于高度位移开关。

## 已实现的数据流程

1. MSVT 从源材质采样和 `SurfaceQuad` 生成共享材质图集；内部四边面 OBJ 桥保留四角和源 UV。已有 Core 从原始 Low `.blend` 读取同样的四边面，并使用 `.mtschunks` 中的原图集和 Raw。
2. 几何在矩形层按空间页切分。子矩形通过父面的同一位置—UV 仿射映射求值，三个基础贴图直接复用，空间页沿用父矩形 gutter 布局。
3. 最后执行三角化。每个矩形的两个三角形共享矩形四角、中心和稳定源帧。Iris 的副切线约定为 `cross(T,N) * handedness`；当前入口要求轴对齐矩形和逐面帧。
4. `.mtscene 1.0` 分发资产采用 lossless 矩形几何编码，保存帧和矩形中心；生成缓存使用浮点页。导入边界验证三角形占据各自独立的矩形角点、帧正交且逐面一致。运行时保留整页 Low，并按 8 m 砖裁剪矩形，重新计算子矩形区域中心后再三角化。浮点页适用 POM 区域契约的前提是已确认轴对齐矩形；布局见[文件契约](../../asset/docs/mtscene-format.md)。
5. `SceneTexture` 通过 `TextureAtlas` 登记真实尺寸，使 Iris 的 `atlasSize` 与 `textureSize` 一致。预拼接图集作为一个容器 sprite 上传，区域布局由资产拥有。

三个通道共享两级 mip。颜色在近似线性空间求平均，法线解码后求平均并归一化，材质离散类别先投票再在同类内求平均。空间分页使用同一图集和同一 mip，保留人工切缝两侧的纹理邻域。原始 atlas 岛的过滤边缘由源材质布局决定。

## 连续性约束

直接 UV 与重建 UV 一致，只能证明打包结果的坐标自洽。相同源表面位置还必须保持材质一致，源连续公共边也必须在转换后继续连续。

已复现的旧三角形转换反例位于 `low/1391.bin` 第 10 个三角形和 `low/1210.bin` 第 9 个三角形，索引均从 0 开始。公共边中点为 `(-32,118.814835,186.867355)`，两侧源颜色都是 `(58,26,27)`；旧逐三角形重采样使一侧变为 `(255,255,96)`。矩形路径保持两侧为 `(58,26,27)`；几何页仅划分归属，采样网格继续沿用矩形路径。

Low-only 原生输出使用 `raw_available=false` 区分“Raw 来源缺失”和“Raw 页真实为空”。运行时对 Raw 来源缺失保持 Low，对 Raw 页真实为空保留空页接管语义。

## 验证范围

验证环境为 Minecraft 1.21.10、NeoForge 21.10.64、Iris 1.9.6、Sodium 0.7.3。

- Core 的三个基础贴图解码字节与源 `.mtschunks` 完全一致；104,312 个 Raw 三角形按 cell 比较逐字节一致。
- 2,326,656 个源表面采样点全部具有对应矩形片段，最大 UV 偏差约 0.000219 个源纹素。
- 434,215 对源位置、UV、法线连续的公共边（其中 100,520 对跨页边）在三通道、两级 mip 双线性采样下的两侧差异处于浮点舍入量级，差异上界为 1/255。
- 实际 GPU 跨页矩形探针包含分数纹素坐标、三通道、两级 mip、非平法线方向和区域 UV 重建；90,000 个检查像素全部通过，覆盖页边界和三角形对角线。
- 完整 Core 包含 3,070 页、491,610 个整页 Low 三角形，图集为 4096×4096。按 8 m 砖裁剪后增加 922,632 个三角形；两种覆盖粒度共用一个顶点缓冲，Iris 80 B stride 下约 323.69 MiB。245,805 个矩形对及全部裁剪片段通过面积、归属、区域角点、中心和帧检查。Complementary Reimagined 5.2.2、KappaPT 18.13、Rethinking Voxels beta9 已完成加载与截图；截图覆盖加载结果，光影附加效果采用逐像素验收。

三通道两级纹理的 RGBA8 数据合计 240 MiB；驱动、CPU 图片、顶点和光影开销单独计量。float32 插值在最近邻采样的精确纹素分界线上可能改变选中的 texel；该限制适用于边界点的逐位比较。

自动法线和 POM 可以钳制到当前子矩形范围；共享 atlas 的光影邻域来源限定为已读取的父面信息。本次资产高度通道为平坦高度。场景仅提交主视图绘制；体素 GI、混合 LOD 截面和特殊方块效果拥有独立的数据要求。
