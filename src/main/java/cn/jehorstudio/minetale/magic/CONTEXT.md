# Magic 跨模块约束

## 概念和依赖

- **技能（skill）** 是使用能力的规则。伽斯特冲击负责索敌、锁定解析、选址、蓄力与蓄力参数换算；统一施法所有者 `MagicCasting` 结算费用。
- **法术（spell）** 是进入世界后独立运行的装置。GB 接收炮口、目标和固定参数，不了解技能、蓄力比例或魔力配置。
- **视效（visual）** 表达当前法术状态，不反向决定伤害。GB 客户端把模型时间轴换算为光束帧，`vfx` 消费帧；GPU 锁定粒子接收跟随实体。
- **特殊效果（effect）** 拥有受影响实体上的规则与状态；Karma 的延迟池不属于发射技能或炮实体。

根入口只装配模块。领域状态分别由 `MagicCasting`、每个 `GasterBlaster`、Karma Attachment 和各视效资源对象拥有，不建立平行占位表或第二份生命周期。

## 权威与持久化

施法公开操作只能在服务端线程调用。网络只接受开始、释放、取消和锁定意图，目标、随机位置、蓄力时长与伤害由服务端决定。`sequence` 单调递增，`castId` 等于对应 BEGIN 的序号；维度、实体状态、请求速率和技能资格在输入边界检查。

`minetale:magic` Attachment 保存魔力、恢复与倍率、流派资格、技能和当前选择。每个实体最多一个施法会话；先消费会话，再执行释放副作用，防止重复释放。释放失败退还累计实际费用，主动取消不退。创造模式只影响即时计费，不覆盖持久倍率。

| 生命周期 | 行为 |
| --- | --- |
| 首次玩家初始化 | 获得伽斯特冲击；已有 Attachment 时不重新赠与撤销的技能 |
| 玩家死亡重生 | 深复制掌握、选择与配置，魔力回满；不复制会话、锁定和 Karma |
| 离开 Level、断线、换维 | 清除技能会话、锁定和输入序号；GB 找不到归属实体时销毁 |
| 保存／加载实体 | 恢复魔法 Attachment 与 Karma 来源欠量；不恢复施法会话，GB 不保存到区块 |
| 客户端资源重载／退出 | 释放或重建离屏目标、Uniform 与光束遮挡图 |

删除 HUD 不改变消耗与退款。客户端状态包只包含锁定 ID 与距离，法术动画由实体同步。协议为 `magic_2`，客户端和服务端必须一致。

## 视觉与命中

模型资源、纹理、出场位移和动画曲线保持现有版本。`GasterBlaster.AnimationFrame` 是嘴部开度、4 Tick 出束、收束和后退的唯一时间轴；客户端使用单调视觉年龄，服务端按权威 Tick 中点判定伤害。

服务端实体位置是固定射击基准。发射期间只按当前时间轴确定圆柱范围、检查传播路径并结算命中，不随后退动画移动或逐 Tick 同步位置。客户端从同步起始时间和阶段时长推导后退，模型、球核与束身共用表现炮口；视觉位移不改变射程、技能占位或伤害范围。

辉光和球核只影响表现，不扩大伤害。只有完整且不透光的实心方块阻挡传播；未加载区域、世界边界及高度外仍阻挡，不为查询加载区块。客户端地形距离图使用固定射击基准，按 Tick 检查世界依赖；结果不上传或决定伤害。

多束光不能按实体遍历顺序覆盖。核心不透明，通过几何光栅化在共享深度目标中保留最近的表面；外部辉光只从已经通过遮挡的核心生成统一 bloom；同形重复来源不会叠亮，雾颜色不进入发光源。单束和多束走同一条路径，不逐层排序。GB 核心始终保持颜色与亮度，退场由口径、球核和长度收束完成，不把旧透明度乘到 RGB 上变黑。此表现变化由用户确认，不改变服务端伤害。

观察深度在透明地形之前冻结，光束颜色在世界和光影最终合成后呈现。不能将水／云写入的最终深度直接当作实墙，也不能借用光影包的 EYES 材质解释光束颜色。测试光影包不定义用户范围；运行时不得按包名、文件名或测试包的私有选项硬编码兼容行为。自定义深度布局尚未解决，具体边界见 [光影兼容](visual/vfx/docs/beam-compatibility.md)。

GB 不产生 BlockLight，不强制重建地形网格；保留炮体背面剔除和眼睛自发光。模型口心与当前资源绑定，不能用新的通用坐标约定替换校准结果。细节见 [GB](spell/gasterblaster/README.md) 与 [视效约束](visual/vfx/README.md)。

标准实体顶点布局使用 GB 的 GPU 批量模型路径：共享静态几何，CPU 采样原骨骼，GPU 变换与生成顶点。Iris 扩展布局在入口回到原 GeckoLib，保持光影材质与阴影阶段；不能把仅验证了原版的 GPU 顶点直接提交给光影。模型批次不拥有实体生命周期、不驱动动画年龄、不改变命中计算。资源重载和退出必须释放共享几何及帧资源。

当前仅实现伽斯特冲击，不包含 GUI、HUD、技能编辑器、其他 GB 技能或 Battle 接入。可复用接口来自现有职责分离，不引入技能图、工厂层次或统一法术继承框架。


GB 的视觉长度由客户端有效渲染视距 × 16 决定；伽斯特冲击释放时以服务端模拟距离 × 16 冻结伤害射程，取代旧 `beam_range` 配置。距离从固定炮口沿发射轴计算，后退动画不扩展伤害。只对处于 entity-ticking 区块的目标判伤，区块加载、世界边界与地形遮挡仍限制实际可达范围。锁定范围保持独立。

GB 实体追踪上限为 32 chunks，原版仍按玩家视距和已追踪炮口区块裁减；炮口区块未同步时不会仅因束身进入画面就获得这束激光。遮挡贴图的 RGB 使用 24 位、1/512 格距离编码，A 保存表面法线轴，解除旧 128 格编码上限且保持原精度。
