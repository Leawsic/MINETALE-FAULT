# MINETALE-FAULT

这是一款受Toby Fox的《UNDERTALE》和《DELTARUNE》启发的二创作品，以Minecraft Mod作为主要呈现载体。

通过持续更新，期望成为一部既融合原作特色又具有鲜明个性的作品。

![alt text](photos/Title.png)

## 目前依赖版本

- Minecraft 1.21.10
- NeoForge 21.10.64
- GeckoLib 5.3-alpha-3
