# MINETALE-FAULT

这是一款受Toby Fox的《UNDERTALE》和《DELTARUNE》启发的二创作品，以Minecraft Mod作为主要呈现载体。

通过持续更新，期望成为一部既融合原作特色又具有鲜明个性的作品。

![标题](photos/Title.webp)

## 模组内容

> 突如其来的⌈错构⌋扰乱了三个世界————⌈Minecraft⌋、⌈UNDERTALE⌋、⌈DELTARUNE⌋。你是方块世界的玩家，但你的⌈灵魂⌋却从躯体飞出，响应那些世界的召唤…………⌈自由⌋仍在你手上，你会如何⌈选择⌋？

目前主要有以下领域：

### 剧情

与出现在世界中或菜单的角色互动、对话、做出选择————事情怎样发展，取决于你怎么做。

### 战斗

模组为了复刻原作的战斗而制作了一个战斗引擎，并在未来计划制作通用编辑器

> 战斗和编辑器在目前的DEMO里并没有出现，因为这个系统仍需要设计和打磨

![战斗界面](photos/battle1.webp)

### ARG与彩蛋

MINETALE-FAULT 是一个有自己世界观的作品，会通过剧情、彩蛋以及后续更新一步步揭开————
